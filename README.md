# Devvrat Kumar Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript to showcase my profile, education, technical skills, projects, and contact details.

## Project Overview

This project is a single-page portfolio website for Devvrat Kumar, a B.Tech student and aspiring developer. It highlights:

- Personal introduction and hero section
- About me summary
- Education background
- Technical skills
- Project highlights
- Contact information and social links

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — main page structure and content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation interaction

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. For local development, you can also run a simple static server if needed.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Features

- Clean and modern portfolio design
- Mobile-friendly responsive layout
- Smooth navigation menu for smaller screens
- Sections for about, education, skills, projects, and contact
- Direct email and GitHub links
